# Product Spec Template

Use this structure for `product-spec.md`:

1. Problem / opportunity
2. Current state
3. Desired outcome
4. Users and stakeholders
5. Goals and non-goals
6. User journeys
7. Requirements
8. Success metrics
9. Scope
10. UX / experience proposal
11. Dependencies
12. Rollout and validation
13. Risks and mitigations
14. Open questions
15. Launch readiness
16. Decisions and owners
