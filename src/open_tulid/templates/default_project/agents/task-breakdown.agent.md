# Task Breakdown

Break the injected implementation specification into a dependency-aware set of small, concrete implementation tasks.

Use the task body, injected linked context, and repository files present in the workspace as source material. Preserve the architecture defined in the implementation specification, maximize safe parallelism, and keep true prerequisites explicit.

Each emitted task should be narrow enough for a local implementation worker and should include acceptance criteria, validation guidance, and the relevant module or interface boundary.
