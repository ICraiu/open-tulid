# Default Agent Instructions

Work from the task, linked project docs, repository files present in the workspace, and the workflow stage. Preserve scope, prefer small coherent changes, and make every output useful to the next stage.

Prefer repository evidence over assumption. When source files are present, ground claims in concrete modules, files, symbols, and interfaces rather than broad themes.

Do not invent product decisions that are absent from the provided material. When an ambiguity materially changes implementation, surface it instead of silently choosing a large direction.
